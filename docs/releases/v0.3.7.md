# Leaf 0.3.7: Jellyfin libraries and progress reporting

- Connect to your Jellyfin server, browse comic libraries and download issues for offline reading. Local unencrypted HTTP requires explicit opt-in.
- Import existing server progress and report reading progress back while reading linked downloads. Remote progress remains enabled. Reporting is best effort: offline failures are not durably retried, and existing downloads do not automatically reconcile changes from other clients.
- Larger touch targets and accessibility labels in Jellyfin controls.
- Exclude the disabled panel-detection model/runtime; retain whole-page reading, local SMB imports and portable backups. Play-flavor external tipping is hidden.

## Testing release and known limits

This is a testing release, not a claim of production-store approval. Pending writes at disconnect, reread/reset behavior and cross-client progress conflicts still need hardening. Opening the first page can reset the server's read status; reaching the last page marks an issue read. Test with that behavior in mind.

## Downloads

Release APKs are signed with Leaf's existing upload key. The AAB is upload-key-signed for Google Play testing. Google Play uses a separate app-signing certificate: a GitHub APK may not install over a Play-installed copy. Do not uninstall a working app just to bypass a signature mismatch; keep your reading data and use the matching update channel.

- Full APK: CBZ, supported CBR, PDF, SMB and Jellyfin.
- F-Droid-flavor APK: excludes the full flavor's RAR dependency. This GitHub file is not a build published by F-Droid.
- AAB: Google Play upload artifact, not directly installable.
- R8 mappings and SHA256SUMS: developer diagnostics and integrity checks.

No iOS app is published by this Android tag. [iOS technical handoff](https://github.com/bclark/leaf-reader/blob/v0.3.7/docs/IOS_ANDROID_037_HANDOFF.md).
